# 밈 생성기 (memeGen)

템플릿을 고르고 → 대사를 채우고 → 사진을 넣어 밈 이미지를 만드는 웹 도구입니다.
빌드 도구 없이 동작하는 순수 HTML/CSS/JavaScript 앱이며, 모든 처리가 브라우저 안에서 끝납니다.
사진은 서버로 전송되지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. (파일 더블클릭도 가능)

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 배포

`main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 저장소 루트를 그대로 GitHub Pages로 배포합니다. 빌드 단계는 없습니다.

**최초 1회만 수동 설정이 필요합니다.** Actions의 기본 토큰은 Pages 사이트를 새로 만들 권한이 없어서, 저장소 설정에서 한 번 켜줘야 합니다.

1. Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 변경
2. Actions 탭에서 `Deploy to GitHub Pages` 워크플로를 **Re-run**

이후 주소는 `https://dhlee0903.github.io/memeGen/` 입니다.

## 사용 방법

1. **템플릿 선택** — 왼쪽 목록에서 원하는 배치를 고릅니다.
2. **대사 채우기** — 오른쪽 패널의 대사 칸에 텍스트를 입력합니다. 캔버스에서 말풍선을 더블클릭해도 해당 입력칸으로 이동합니다.
3. **사진 넣기** — 사진 칸의 `사진 선택` 버튼을 누르거나, 캔버스의 사진 칸 위로 이미지 파일을 **드래그 앤 드롭**합니다. 사진 칸을 더블클릭해도 파일 선택창이 열립니다.
4. **위치 조정** — 캔버스에서 칸을 드래그해 옮기고, 모서리 핸들로 크기를 바꿉니다. 방향키로 1px씩(Shift와 함께 10px씩) 미세 조정할 수 있습니다.
5. **PNG 다운로드** — 화면 배율과 상관없이 원본 크기의 2배 해상도로 저장됩니다.

### 만화 페이지를 그대로 템플릿으로 쓰기

말풍선이 비어 있는 만화 페이지가 이미 있다면, 좌표를 직접 찍을 필요가 없습니다.

1. 왼쪽 `배경 이미지 업로드`로 만화 페이지를 올립니다.
2. **빈 말풍선을 자동으로 찾아 대사 칸으로 만들어 줍니다.** (읽는 순서대로 정렬)
3. 오른쪽 패널에서 칸마다 대사를 채웁니다.
4. `＋ 사진 칸`으로 폰·캐릭터 같은 사진을 칸 위에 얹습니다. 사진은 말풍선 아래에 깔립니다.

자동으로 찾지 못했거나 나중에 다시 돌리고 싶으면 상단의 `🔍 말풍선 자동 찾기` 버튼을 누르면 됩니다.
잘못 잡힌 칸은 `✕`로 지우고, 위치는 캔버스에서 드래그해 맞추면 됩니다.

원리는 단순합니다 — 배경 이미지에서 **검은 윤곽선에 둘러싸인 흰 덩어리**를 찾습니다.
스크린톤(회색 점)과 검은 선은 흰색이 아니라서 걸러지고, 페이지 여백과 칸 사이 흰 공간은
서로 이어져 하나의 거대한 덩어리가 되므로 면적 상한으로 걸러집니다. 남은 후보 중
속이 꽉 차고(면적 대비 62% 이상) 지나치게 가늘거나 길지 않은 것만 말풍선으로 봅니다.

이렇게 만든 결과는 `저장`이나 `JSON 내보내기`로 보관하면 다음부터 바로 불러 쓸 수 있는
나만의 템플릿이 됩니다.

### 그 외 내 이미지로 시작하기

만화가 아닌 일반 사진을 올린 뒤 `＋ 대사 칸` / `＋ 사진 칸`으로 자리를 직접 그려 넣어도 됩니다.

## 내장 템플릿

| 템플릿 | 구성 |
| --- | --- |
| **원본 만화 페이지** | 만화 페이지 그림이 배경 · 그림에 그려진 빈 말풍선 12칸 + 칸별 사진 자리 8개 (기본 템플릿) |
| 만화 8컷 | 2열 × 4행 만화 칸 + 칸마다 말풍선 (“이거 다 똑같은 거 아니에요?” 형식) |
| 만화 4컷 | 2열 × 2행 만화 칸 + 말풍선 |
| 비교 2단 | 왼쪽 반응 사진 · 오른쪽 문구 2줄 |
| 4분할 비교 | 사진 4장 + 각각 아래 설명 |
| 기본 밈 | 사진 한 장 + 위/아래 흰 글씨(검은 외곽선) |
| 말풍선 3개 | 사진 한 장 위에 자유 배치 말풍선 3개 |
| 빈 캔버스 | 아무것도 없는 상태에서 시작 |

## 단축키

| 키 | 동작 |
| --- | --- |
| 방향키 | 선택한 칸 1px 이동 (Shift: 10px) |
| Delete / Backspace | 선택한 칸 삭제 |
| Esc | 선택 해제 |
| Ctrl/Cmd + Z | 되돌리기 |
| Ctrl/Cmd + Shift + Z | 다시 실행 |
| Ctrl/Cmd + S | 브라우저에 저장 |
| Ctrl/Cmd + E | PNG 내보내기 |

## 저장 방식

- **저장 / 불러오기**: 브라우저 `localStorage`에 보관합니다. 브라우저 데이터를 지우면 함께 사라지고, 용량 한도(보통 5MB)가 있어 사진이 많으면 저장에 실패할 수 있습니다.
- **JSON 내보내기 / 가져오기**: 사진까지 포함한 파일로 저장해 다른 기기로 옮길 수 있습니다.
- 업로드한 사진은 긴 변 기준 1600px로 자동 축소되어 보관됩니다.

## 코드 구조

```
index.html          화면 구조
css/style.css       스타일
assets/templates/   내장 템플릿 이미지
  comic-8-page.webp   원본 만화 페이지 (622×959)
  comic-8-page.js     위 이미지를 data URI 로 담은 것 — 앱이 실제로 읽는 쪽
js/templates.js     내장 템플릿 정의 · 슬롯 기본값
js/renderer.js      캔버스 렌더링 (말풍선 · 줄바꿈 · 이미지 배치 · 내보내기)
js/detect.js        배경 만화에서 빈 말풍선 자동 인식
js/editor.js        캔버스 편집 (선택 · 이동 · 크기조절 · 확대축소 · 키보드)
js/app.js           상태 관리 · 속성 패널 · 저장/불러오기 · 다운로드
```

### 템플릿 추가하기

`js/templates.js`의 `BUILDERS` 배열에 템플릿을 반환하는 함수를 추가하면 갤러리에 자동으로 나타납니다.

```js
function myTemplate() {
  return {
    id: 'my-template',
    name: '내 템플릿',
    desc: '설명 한 줄',
    width: 800, height: 800,
    background: '#ffffff',
    panels: [{ x: 16, y: 16, w: 768, h: 768 }],   // 만화 칸(선택)
    slots: [
      imageSlot({ name: '배경 사진', x: 16, y: 16, w: 768, h: 768 }),
      textSlot({ name: '대사 1', x: 40, y: 40, w: 300, h: 110, text: '대사' })
    ]
  };
}
```

슬롯 속성은 `js/templates.js` 상단 주석에 정리되어 있습니다.

이미지를 상대 경로 대신 data URI 로 담은 이유는 두 가지입니다. `index.html` 을 파일로 직접
열었을 때(`file://`) 상대 경로 이미지는 캔버스를 오염시켜 PNG 저장이 막히고, 한 파일로 합쳐
배포할 때 외부 요청 없이 그대로 동작해야 하기 때문입니다.

## 참고

`assets/templates/comic-8-page.webp` 는 저작권이 있는 원작 만화 페이지입니다. 개인적으로 밈을
만드는 용도라면 통상적인 범위지만, 이 저장소를 공개 배포하거나 상업적으로 쓸 때는 권리 관계를
확인하세요. 나머지 내장 템플릿은 칸 배치와 말풍선 구조만 있고 그림은 들어 있지 않습니다.
