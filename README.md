# 밈 생성기 (memeGen)

템플릿을 고르고 → 대사를 채우고 → 사진을 넣어 밈 이미지를 만드는 웹 도구입니다.
빌드 도구 없이 동작하는 순수 HTML/CSS/JavaScript 앱이며, 모든 처리가 브라우저 안에서 끝납니다.
사진은 서버로 전송되지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. (파일 더블클릭도 가능)

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8080
# http://localhost:8080 접속
```

## 배포

`main`에 푸시하면 `.github/workflows/deploy-pages.yml`이 저장소 루트를 그대로 GitHub Pages로 배포합니다. 빌드 단계는 없습니다.

**최초 1회만 수동 설정이 필요합니다.** Actions의 기본 토큰은 Pages 사이트를 새로 만들 권한이 없어서, 저장소 설정에서 한 번 켜줘야 합니다.

1. Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 변경
2. Actions 탭에서 `Deploy to GitHub Pages` 워크플로를 **Re-run**

이후 주소는 `https://dhlee0903.github.io/memeGen/` 입니다.

## 템플릿 게시 (관리자)

만든 템플릿을 사이트에 올려 누구나 쓰게 할 수 있습니다. **별도 DB나 서버는 없습니다** —
저장소가 곧 데이터베이스입니다.

```jsonc
// assets/templates/index.json
{
  "templates": [                       // 게시했거나 내장을 덮어쓴 것
    { "id": "user-abc", "name": "...", "file": "assets/templates/user/user-abc.json" },
    { "id": "comic-8",  "name": "...", "file": "...", "overrides": true }
  ],
  "trash": [                           // 지운 것 — 관리자만 보고, 되살릴 수 있다
    { "id": "quad-4", "name": "4분할 비교", "builtin": true, "deletedAt": "..." },
    { "id": "user-xyz", "name": "...", "file": "assets/templates/trash/user-xyz.json" }
  ]
}
```

앱은 시작할 때 이 두 가지를 읽어 갤러리 맨 앞에 붙입니다. 게시는 이 파일들을
GitHub API 로 커밋하는 것이고, 커밋되면 Pages 가 다시 배포되면서 모두에게 보입니다.

### 게시하는 법

1. `https://dhlee0903.github.io/memeGen/admin.html` 로 들어갑니다.
2. 평소처럼 템플릿을 고쳐 말풍선 위치·크기를 맞춥니다.
3. 위쪽 **🚀 게시** 를 누르고 이름과 설명을 입력합니다.
4. 처음 한 번은 GitHub 토큰을 물어봅니다. 아래를 참고해 발급하세요.
5. 1분쯤 뒤 배포가 끝나면 모두에게 보입니다. 같은 이름으로 다시 게시하면 덮어씁니다.

### 수정 · 삭제 · 휴지통

관리자 모드에서는 갤러리 카드 오른쪽 위에 관리 버튼이 붙습니다.

| 버튼 | 하는 일 |
| --- | --- |
| `🗑` | 휴지통으로 보낸다 (내장·게시본 모두) |
| `↺` | 수정을 취소하고 원래 내장 템플릿으로 (수정된 카드에만) |

**내장 템플릿 수정**은 툴바의 `💾 이 템플릿 수정` 을 씁니다. 같은 id 로 게시되어 갤러리의
그 자리를 대체하고, 카드에 `수정됨` 표시가 붙습니다. `🚀 새로 게시` 는 항상 별개의 새 템플릿을
만듭니다.

**휴지통**은 왼쪽 패널 아래에 있고 관리자에게만 보입니다. 방문자는 휴지통에 있는 템플릿을
볼 수 없습니다.

- **복원** — 갤러리로 되돌립니다. 게시본은 파일이 `trash/` 에서 `user/` 로 다시 옮겨지므로
  내용이 그대로 살아납니다.
- **완전 삭제(`✕`)** — 게시본에만 있습니다. 내장 템플릿은 코드에 있어서 완전히 지운다는
  개념이 없고, 휴지통에 있는 동안 갤러리에서 빠져 있을 뿐입니다.

### 토큰

GitHub → Settings → Developer settings → **Fine-grained tokens** 에서 이 저장소만 지정하고
**Contents: Read and write** 권한으로 발급하세요.

**주소(`admin.html`)는 잠금장치가 아닙니다.** 누구나 열 수 있고, 열어도 관리자 화면이 보입니다.
실제 권한은 토큰이 쥐고 있어서 토큰이 없으면 아무것도 게시하지 못합니다. 토큰은 이 브라우저의
`localStorage` 에만 저장되고 저장소에는 들어가지 않습니다. 공용 컴퓨터에서 썼다면 `토큰 지우기`
를 눌러 지우세요.

내장 템플릿을 고쳐 게시하면 배경 그림은 다시 올라가지 않고 `asset:<키>` 참조로만 기록됩니다.
직접 올린 배경은 게시 파일 안에 data URI 로 함께 담깁니다.

## 사용 방법

1. **템플릿 선택** — 왼쪽 목록에서 원하는 배치를 고릅니다.
2. **대사 채우기** — 오른쪽 패널의 대사 칸에 텍스트를 입력합니다. 캔버스에서 말풍선을 더블클릭해도 해당 입력칸으로 이동합니다.
3. **사진 넣기** — 사진 칸의 `사진 선택` 버튼을 누르거나, 캔버스의 사진 칸 위로 이미지 파일을 **드래그 앤 드롭**합니다. 사진 칸을 더블클릭해도 파일 선택창이 열립니다.
4. **위치 조정** — 캔버스에서 칸을 드래그해 옮기고, 모서리 핸들로 크기를 바꿉니다. 방향키로 1px씩(Shift와 함께 10px씩) 미세 조정할 수 있습니다.
5. **PNG 다운로드** — 화면 배율과 상관없이 원본 크기의 2배 해상도로 저장됩니다.

### 만화 페이지를 그대로 템플릿으로 쓰기

말풍선이 비어 있는 만화 페이지가 이미 있다면, 좌표를 직접 찍을 필요가 없습니다.

1. 왼쪽 `배경 이미지 업로드`로 만화 페이지를 올립니다.
2. **빈 말풍선을 자동으로 찾아 대사 칸으로 만들어 줍니다.** (읽는 순서대로 정렬)
3. 오른쪽 패널에서 칸마다 대사를 채웁니다.
4. `＋ 사진 칸`으로 폰·캐릭터 같은 사진을 칸 위에 얹습니다. 사진은 말풍선 아래에 깔립니다.

자동으로 찾지 못했거나 나중에 다시 돌리고 싶으면 상단의 `🔍 말풍선 자동 찾기` 버튼을 누르면 됩니다.
잘못 잡힌 칸은 `✕`로 지우고, 위치는 캔버스에서 드래그해 맞추면 됩니다.

원리는 단순합니다 — 배경 이미지에서 **검은 윤곽선에 둘러싸인 흰 덩어리**를 찾습니다.
스크린톤(회색 점)과 검은 선은 흰색이 아니라서 걸러지고, 페이지 여백과 칸 사이 흰 공간은
서로 이어져 하나의 거대한 덩어리가 되므로 면적 상한으로 걸러집니다. 남은 후보 중
속이 꽉 차고(면적 대비 62% 이상) 지나치게 가늘거나 길지 않은 것만 말풍선으로 봅니다.

이렇게 만든 결과는 `저장`이나 `JSON 내보내기`로 보관하면 다음부터 바로 불러 쓸 수 있는
나만의 템플릿이 됩니다.

### 그 외 내 이미지로 시작하기

만화가 아닌 일반 사진을 올린 뒤 `＋ 대사 칸` / `＋ 사진 칸`으로 자리를 직접 그려 넣어도 됩니다.

## 내장 템플릿

| 템플릿 | 구성 |
| --- | --- |
| **원본 만화 페이지** | 만화 페이지 그림이 배경 · 빈 말풍선 12칸(5·6컷 반응 대사는 기본값으로 채워져 있음) + 칸별 사진 자리 8개 (기본 템플릿) |
| **삼형제 6컷** | 만화 페이지 그림이 배경 · 말풍선이 없는 페이지라 테두리 없는 흰 박스 6개를 얹어 둠 (1컷은 기본 문구 채워짐) |
| 만화 8컷 | 2열 × 4행 만화 칸 + 칸마다 말풍선 (“이거 다 똑같은 거 아니에요?” 형식) |
| 만화 4컷 | 2열 × 2행 만화 칸 + 말풍선 |
| 비교 2단 | 왼쪽 반응 사진 · 오른쪽 문구 2줄 |
| 4분할 비교 | 사진 4장 + 각각 아래 설명 |
| 기본 밈 | 사진 한 장 + 위/아래 흰 글씨(검은 외곽선) |
| 말풍선 3개 | 사진 한 장 위에 자유 배치 말풍선 3개 |
| 빈 캔버스 | 아무것도 없는 상태에서 시작 |

## 글꼴

대사 칸마다 **고딕 / 명조 / 굴림·돋움** 중에 고를 수 있습니다.

웹폰트를 내려받지 않고 **기기에 설치된 글꼴**을 씁니다. 한글 웹폰트는 한 벌에 1MB 안팎이라
세 벌을 담으면 앱이 그만큼 무거워지기 때문입니다. 대신 그 글꼴이 없는 기기에서는 뒤쪽 후보로
대체되므로, 보는 사람의 OS에 따라 모양이 조금씩 다를 수 있습니다.
(윈도우·맥에는 세 종류가 모두 있거나 비슷한 대체 글꼴이 있습니다.)

## 배경 지우기 (누끼)

사진 칸에서 `올릴 때 배경 지우기(누끼)` 를 켜두면 업로드하는 사진의 배경을 지웁니다.
이미 넣은 사진은 `지금 배경 지우기` 로 처리합니다.

가장자리에서 시작해 비슷한 색이 이어지는 만큼을 배경으로 보고 지웁니다. **흰 배경 제품
사진처럼 배경이 단색인 사진에 잘 맞고**, 풍경이나 실내처럼 배경이 복잡한 사진은 잘 안 됩니다.
그런 사진까지 처리하려면 학습 모델이 필요한데 수십 MB라 이 앱에는 담지 않았습니다.

처리는 전부 브라우저 안에서 일어나므로 사진이 밖으로 나가지 않습니다.

## 모바일

화면이 860px 이하로 좁아지면 레이아웃이 바뀝니다.

- **캔버스가 화면을 다 씁니다.** 좌·우 패널을 그대로 쌓으면 캔버스가 화면의 1/4로 밀려
  편집이 안 됩니다.
- **아래 탭바**(`▦ 템플릿` / `✎ 칸 편집`)로 패널을 아래에서 올라오는 시트로 엽니다.
  템플릿을 고르면 시트가 닫혀 결과가 바로 보이고, 캔버스에서 대사 칸을 더블탭하면
  편집 시트가 열리면서 그 칸으로 갑니다.
- **상단바**는 한 줄로 줄고, 저장·불러오기·JSON 은 `⋯` 안으로 들어갑니다.
- 도구 막대는 줄바꿈 대신 가로로 스크롤됩니다.
- 입력칸 글자를 16px 로 둡니다. 그보다 작으면 iOS 사파리가 입력할 때 화면을 확대합니다.

## 저장 방식

- **저장 / 불러오기**: 브라우저 `localStorage`에 보관합니다. 브라우저 데이터를 지우면 함께 사라지고, 용량 한도(보통 5MB)가 있어 사진이 많으면 저장에 실패할 수 있습니다.
- **JSON 내보내기 / 가져오기**: 사진까지 포함한 파일로 저장해 다른 기기로 옮길 수 있습니다.
- 업로드한 사진은 긴 변 기준 1600px로 자동 축소되어 보관됩니다.

### 템플릿 추가하기

`js/templates.js`의 `BUILDERS` 배열에 템플릿을 반환하는 함수를 추가하면 갤러리에 자동으로 나타납니다.

```js
function myTemplate() {
  return {
    id: 'my-template',
    name: '내 템플릿',
    desc: '설명 한 줄',
    width: 800, height: 800,
    background: '#ffffff',
    panels: [{ x: 16, y: 16, w: 768, h: 768 }],   // 만화 칸(선택)
    slots: [
      imageSlot({ name: '배경 사진', x: 16, y: 16, w: 768, h: 768 }),
      textSlot({ name: '대사 1', x: 40, y: 40, w: 300, h: 110, text: '대사' })
    ]
  };
}
```

슬롯 속성은 `js/templates.js` 상단 주석에 정리되어 있습니다.

이미지를 상대 경로 대신 data URI 로 담은 이유는 두 가지입니다. `index.html` 을 파일로 직접
열었을 때(`file://`) 상대 경로 이미지는 캔버스를 오염시켜 PNG 저장이 막히고, 한 파일로 합쳐
배포할 때 외부 요청 없이 그대로 동작해야 하기 때문입니다.

## 참고

`assets/templates/` 안의 만화 페이지 이미지는 저작권이 있는 원작입니다. 개인적으로 밈을
만드는 용도라면 통상적인 범위지만, 이 저장소를 공개 배포하거나 상업적으로 쓸 때는 권리 관계를
확인하세요. 나머지 내장 템플릿은 칸 배치와 말풍선 구조만 있고 그림은 들어 있지 않습니다.
